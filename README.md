# Ordenación: mapa conceptual y diagramas de flujo

Una página para entender cómo se ordena una lista de datos, basada en el capítulo 10 del libro *Fundamentos de programación* de Luis Joyanes (2020).

Reúne los métodos de ordenación del capítulo en un mapa conceptual y muestra cómo funciona cada uno, paso a paso, con diagramas de flujo animados. También incluye Radix Sort, un método que ordena números sin compararlos entre sí.

## Cómo usarla

1. **Lee la introducción.** Al principio está lo esencial: qué significa ordenar y en qué se diferencian la ordenación interna y la externa.
2. **Explora el mapa conceptual.** Cada tarjeta muestra un método con una breve descripción, qué tan rápido es y qué tan eficiente resulta. Toca una tarjeta para ver más detalles.
3. **Prueba el laboratorio.** Elige un método en las pestañas de arriba y pulsa **▶** para verlo en acción. El diagrama, el pseudocódigo y las barras avanzan juntos, y Bit, el pequeño robot, salta sobre el número que se está usando en cada momento.
   - Usa **◀** y **▶|** para avanzar o retroceder de a un paso.
   - Mueve la barra de velocidad para ir más lento o más rápido.
   - Pulsa **Ejemplo del libro** para usar los mismos números del capítulo, o **Aleatorio** para probar con otros.
4. **Compara los métodos.** La tabla resume cuál conviene en cada caso, y la carrera muestra cuánto trabajo hace cada uno con la misma lista.
5. **Conoce Radix Sort.** La última sección explica, con un ejemplo, cómo ordena repartiendo los números en cubetas según sus dígitos.
